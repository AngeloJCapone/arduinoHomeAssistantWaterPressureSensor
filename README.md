When setting up the project locally, remove the '.template' extension from the 'secret_values.h.template' file so that it only appears as 'secret_values.h', and then fill THAT file with the appropriate values for the local WIFI and MQTT information

It is easiest to push this program to an arduino board using the Arduino IDE environment, their website and setup instructions can be found here: https://www.arduino.cc/en/software/
